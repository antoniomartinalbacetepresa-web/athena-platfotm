# ATHENA TYCHE

# Arquitectura del Sistema

## Objetivo

Crear una plataforma escalable para ayudar a los usuarios a tomar mejores decisiones de inversión mediante análisis cuantitativo e inteligencia artificial.

---

# Componentes

## 1. Aplicación móvil

Tecnología:

Flutter

Funciones:

- Registro de usuarios
- Dashboard
- Cartera
- Mercado
- Alertas
- Perfil

---

## 2. Backend

Tecnología:

FastAPI (Python)

Funciones:

- Gestión de usuarios
- Gestión de carteras
- Motor ATHENA
- API de acciones
- Noticias
- Alertas

---

## 3. Base de datos

Tecnología:

PostgreSQL

Guardará:

- Usuarios
- Carteras
- Operaciones
- Recomendaciones
- Historial
- Aprendizaje

---

## 4. Motor ATHENA

Será el cerebro de la aplicación.

Se encargará de:

- ATHENA Score
- Gestión del riesgo
- Recomendaciones
- Aprendizaje continuo
- Explicaciones

---

# Filosofía

La aplicación nunca ejecutará operaciones financieras.

Su objetivo será ayudar al usuario a tomar mejores decisiones mediante información clara y explicable.
